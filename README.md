# BreakTimer Ultra — 全画面ウィンドウでも隠れない休憩タイマー

「**20分作業したら20秒間目を休める**（20-20-20ルール）」を確実に実践するためのWindowsデスクトップ休憩タイマーアプリです。

YouTube・Netflix等の全画面動画再生、ブラウザの全画面モード（F11）、全画面ゲームなどを起動していても、**休憩画面が背面に隠れず確実に最前面に表示される**ように設計されています。

---

## 1. BreakTimerの仕様調査と「全画面で隠れる問題」の原因

### BreakTimerの仕様
- **20-20-20 ルール**: 20分ごとに20秒間、20フィート（約6m）先を見て目を休めるデジタル眼精疲労防止の標準ルール。
- **通知・オーバーレイ**: 休憩時刻になるとカウントダウンウィンドウ（円形プログレスバー）を表示。
- **操作**: スヌーズ（Snooze / 延期）、スキップ（Skip）、今すぐ終了。
- **タスクトレイ常駐**: バックグラウンドでタイマーを監視。

### なぜ従来のBreakTimerは全画面で隠れてしまうのか？
BreakTimerのソースコード（`tom-james-watson/breaktimer-app`）を調査したところ、以下の原因が特定されました：
1. **`showInactive()` & `focusable: false` の使用**:
   - 他の作業の邪魔をしないよう非アクティブ状態でウィンドウを生成（`showInactive()`）しているため、全画面アプリ（フォアグラウンド）の背面に追いやられてしまう。
2. **Windowsのフォアグラウンドロック制約**:
   - Windows OSではバックグラウンドプロセスが勝手にフォアグラウンドになることを制限しており、通常の `setAlwaysOnTop(true)` だけでは全画面アプリより上位に表示できない。
3. **Z-Order（重なり順）の再評価が行われない**:
   - フルスクリーンアプリ（DirectXやブラウザF11）は定期的に自ウィンドウを最上位に維持・再描画するため、一度だけ最前面設定されたウィンドウは数ミリ秒〜数秒で裏に隠れてしまう。

## 2. BreakTimer Ultra による解決技術

本アプリでは、Windows Win32 API（`user32.dll`, `kernel32.dll`）を用いて以下の**多重防護機構**を実装しています：

1. **強制フォアグラウンド奪取 (`AttachThreadInput` テクニック)**:
   - 現在のフォアグラウンドウィンドウ（全画面アプリ）のスレッドに入力処理を一時アタッチし、OSのフォアグラウンドロックを正当に突破。自ウィンドウを最前面に引き上げます。
2. **Z-Order Enforcer（継続的最上位維持ループ）**:
   - 休憩表示中、100ms周期で `SetWindowPos(hwnd, HWND_TOPMOST, ...)` を呼び出し続けます。全画面ゲームや動画プレーヤーが前面に来ようとしても即座に最前面へ復帰します。
3. **全モニター対応 半透明Backdropオーバーレイ**:
   - マルチモニター環境を含む全仮想画面（Virtual Desktop）をカバーする半透明ダーク背景で覆い、全画面アプリの刺激を和らげて目を休ませます。
4. **安全・快適な操作性**:
   - 急ぎの作業時でも `Esc` キー、`Space` キー、または画面上のボタンでいつでも「スキップ」「スヌーズ」「今すぐ終了」が可能です。

## 3. 主な機能

- ⏱ **20-20-20 ルール（標準）**: 作業20分 / 休憩20秒 / スヌーズ2分
- 🎨 **美しいダークテーマUI**:
  - 円形プログレスサークル（滑らかなCanvas描画）
  - 大きなカウントダウン表示（秒単位）
  - 目を休めるためのガイダンスメッセージ
- 🎬 **Netflix・動画対策（自動一時停止＆背後クリック機能）**:
  - **メディア自動一時停止**: 休憩が始まると自動的にWindowsのメディア停止キー（`VK_MEDIA_PLAY_PAUSE`）を送信し、NetflixやYouTubeの動画をその場で自動停止。
  - **画面上の操作ボタン＆Spaceキー**: 休憩カード上の「⏯ 動画を一時停止/再開」ボタン、または `Space` キーでいつでも動画の再生・停止を操作可能。
  - **「👁 背後を操作する (ミニ表示)」ボタン**: クリックすると全画面Backdropが消え、右上の小さなミニタイマーに縮小。背後のNetflixの停止ボタンや字幕設定などを直接マウスでクリック可能！
  - **表示スタイルの切り替え**: 「全画面オーバーレイ（推奨）」または「コンパクト浮動カード（背後のNetflixが常に操作可能）」を選択可能。
- 🔊 **高品質サウンド通知**:
  - BreakTimer純正のサウンドテーマ（`ping`, `gong`, `bloop`, `blip`, `scifi`）
  - 休憩開始時・終了時の効果音
- 🛡 **全画面テスト機能**:
  - ダッシュボードの「⚡ 全画面テスト (5秒)」ボタンで、ブラウザ全画面や動画全画面にした状態でも隠れないかを即座にテスト可能。
- ⚙ **自由なカスタマイズ**:
  - 作業間隔（1分〜60分）
  - 休憩時間（5秒〜180秒）
  - スヌーズ時間（1分〜15分、初期値5分）
  - 全画面オーバーレイの暗度（30%〜95%）
  - メディア自動一時停止のON/OFF
  - 表示スタイルの切り替え
  - サウンドの有効/無効およびテーマ選択
- 📌 **タスクトレイ（システムトレイ）常駐＆動作ログ**:
  - ウィンドウを閉じてもトレイに最小化
  - ツールチップに「次回 13:50:30 (あと 18分)」と正確な時刻を表示
  - 画面上に「📜 動作履歴ログ」を搭載し、何時何分に休憩が開始・終了したかを透明に記録

## 4. 起動方法

### 方法1: バッチファイルをダブルクリック
フォルダ内の `run.bat` をダブルクリックするだけで起動します。

### 方法2: コマンドラインから実行
```bash
python main.py
```
（コンソールを表示せずに静かに起動したい場合は `pythonw main.py`）

---

## 5. 全画面保護テストの実行

フルスクリーンの最前面アプリを模した専用テストスクリプトを用意しています：
```bash
python test_fullscreen_protection.py
```
画面全体を覆うシミュレーション全画面ウィンドウが表示された後、自動的にBreakTimerの休憩画面がその上に割り込んで最前面を維持することを検証できます。
